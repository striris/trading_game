# The Trading Sandbox

The Trading Sandbox is an interactive collection of browser-based finance simulations that help learners understand real-world market concepts through play.

It is designed to help learners explore trading and risk management concepts through realistic, hands-on simulations.

This project currently includes two independent web-based games:

1. **Portfolio Hedging Game** — Learn how to protect investments from market downturns using hedging instruments such as options, futures, and short positions.  
2. **Market Making Game** — Experience how traders quote bid-ask spreads, manage inventory, and earn profit while maintaining market liquidity.

Each game runs entirely in the browser using React and Tailwind CSS. No installation or build process is required.
